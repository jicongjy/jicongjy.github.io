# Hong Jiyoung Portfolio

Static portfolio site for [jicongjy.github.io/portfolio](https://jicongjy.github.io/portfolio/).

Source files are maintained separately; this repository contains only the public build used by GitHub Pages.

The site lives in `portfolio/`. The root `index.html` and `404.html` are a playful empty page (no personal information, no links). The root `work.html` silently forwards old detail links to `portfolio/work.html`.
